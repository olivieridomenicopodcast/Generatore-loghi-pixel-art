# Schede delle modifiche

Una scheda per ogni modifica, accanto al codice. Chi arriva dopo (persona o AI) legge la scheda invece di indovinare.

## Regole
- Si scrive **come funziona adesso**, non la cronaca di come ci sei arrivato.
- Nome del file: la sigla della richiesta (`V1-orari-ristorante.md`) oppure il numero progressivo (`003-descrizione.md`).
- Struttura fissa: vedi `TEMPLATE.md`.
- Se una modifica cambia un comportamento descritto in una scheda vecchia, in fondo a quella scheda si aggiunge un paragrafo «Aggiornamento AAAA-MM-GG» con il rimando alla nuova.
- Le schede le aggiorna Claude Code a fine lavoro (skill `chiudere-una-modifica`).
